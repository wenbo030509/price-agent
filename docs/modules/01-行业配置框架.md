## 一、模块定位

### 1.1 要解决的问题

当前项目没有任何"行业"概念。所有逻辑（字段、标签、权重、Prompt）要么 hardcoded 在代码里，要么写在 system prompt 的静态文本中。换一个品类（如笔记本）需要改代码。

### 1.2 目标

- 定义一套行业 Config 的 Schema 标准（哪些字段必填、哪些可选、类型约束）
- 手机品类作为第一个实例，写一份完整的 `mobile.py` Config
- Config 从 `Settings` 注入到 `ReActAgent`，再按需传递到各工具模块
- 后续模块（M2-M5）都从这个 Config 读取行业参数，代码中不再 hardcoded 行业逻辑

### 1.3 不改什么

- `Settings` 类的现有字段（model、api_key 等）
- `ReActAgent.__init__()` 的现有参数签名
- `app.py → initialize()` 的启动流程

## 二、Config Schema 设计

### 2.1 Schema 总览

```python
IndustryConfig = {
    # ── 基础标识 ──
    "industry": str,              # "mobile" | "laptop" | ...
    "category": str,              # 默认品类名，如 "手机"

    # ── 商品 Schema 映射 ──
    "embedding_fields": list,     # 哪些字段拼接后做 embedding
    "filter_fields": {
        "exact": list,            # 精确匹配字段（brand, processor_brand, ...）
        "range": list,            # 范围过滤字段（price, battery, ...）
        "tag_match": list,        # 多标签匹配字段（use_case_tags）
    },

    # ── 排序策略 ──
    "sort_strategies": dict,      # {"value": "公式", "price": "公式", ...}

    # ── 枚举值体系 ──
    "performance_tier_map": dict, # {"flagship": 100, "mid": 65, "budget": 35}
    "use_case_taxonomy": list,    # ["gaming", "photography", ...]
    "processor_normalize": dict,  # {"骁龙": "sd", "天玑": "mt", ...}

    # ── Prompt 模板（各模块按需读取）──
    "prompts": {
        "decompose": str,         # 用于 M4 意图分解
        "rerank": str,            # 用于 M4 LLM Rerank
        "rag_system": str,        # 用于 M3 RAG 检索 prompt
        "slot_questions": dict,   # 用于 M5 槽位追问
    },

    # ── 推荐与对比参数 ──
    "recommend_dimensions": list, # [{"name":"性能","key":"performance_tier","weight":0.30}, ...]
    "compare_dimensions": list,   # 同上，用于对比模式

    # ── 购物槽位 ──
    "shopping_slots": list,       # 用于 M5 槽位填充
    "max_slot_questions": int,
}
```

### 2.2 设计原则

1. **Schema 本身不含业务逻辑** — 只描述"是什么"，不描述"怎么用"。各模块按需读取各自关心的字段。
2. **所有字段平级** — 不嵌套过深。每个模块读取时不用钻多层 dict。
3. **有合理默认值** — 未配置的字段各模块有 fallback，Config 不完整也能跑（降级到当前行为）。
4. **手机 Config 是完整实例** — 其他品类对照手机 Config 即可知道要填什么。

### 3.2 新增：`config/industry_loader.py`

Config 加载器，职责单一：从 `config/industries/<name>.py` 加载行业 Config。

```python
"""
config/industry_loader.py
行业 Config 加载器。按行业名加载对应的配置模块。
"""
import importlib
from typing import Dict, Optional

# 模块级缓存
_industry_configs: Dict[str, dict] = {}

# 默认 Config（当行业 Config 缺失某字段时的 fallback）
DEFAULT_CONFIG = {
    "sort_strategies": {
        "value": "performance_score / price * 10000",
        "price": "-price",
    },
    "performance_tier_map": {"flagship": 100, "mid": 65, "budget": 35},
    "max_slot_questions": 3,
    "enable_llm_rerank": False,       # 默认关闭，M4 可开启
    "enable_vector_recall": False,    # 默认关闭，M2 可开启
}


def load_industry_config(industry: str = "mobile") -> dict:
    """
    加载行业 Config。模块级缓存，同一行业只加载一次。
    
    Args:
        industry: 行业标识，对应 config/industries/<industry>.py
        
    Returns:
        完整的行业 Config dict，缺失字段用 DEFAULT_CONFIG 补齐
    """
    if industry in _industry_configs:
        return _industry_configs[industry]
    
    try:
        module = importlib.import_module(f"config.industries.{industry}")
        raw = getattr(module, f"{industry.upper()}_CONFIG", {})
    except (ImportError, AttributeError):
        raw = {}
    
    # 用默认值补齐缺失字段
    config = {**DEFAULT_CONFIG, **raw}
    _industry_configs[industry] = config
    return config


def get_industry_config(industry: str, key: str, default=None):
    """按 key 读取 Config 中的单个字段"""
    config = load_industry_config(industry)
    return config.get(key, default)
```

## 四、Config 消费方式

各模块通过以下方式读取行业配置：

### 方式一：从 ReActAgent 实例读取（M5 使用）

```python
# react_engine.py 内部
slots = self.industry_config.get("shopping_slots", [])
```

### 方式二：从工具函数内部读取（M2/M4 使用）

在 `semantic_search_tool.py` 中，通过 `PlatformParallelAgent` 间接获取 Config。`PlatformParallelAgent` 在 `__init__` 时从 `Settings` 获取行业 Config：

```python
# platforms/parallel_agent.py
class PlatformParallelAgent:
    def __init__(self):
        from config import Settings
        self.industry_config = Settings().industry_config
```

### 方式三：直接 import（M3 使用）

```python
# tools/rag_tool.py
from config.industry_loader import get_industry_config
config = get_industry_config("mobile", "prompts", {})
rag_prompt = config.get("rag_system", "")
```

选择原则：在 `ReActAgent` 生命周期内的用方式一/二，独立于 Agent 生命周期的用方式三。
